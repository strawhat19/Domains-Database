# Programming Language Marks

Unmodified SVGs vendored from Simple Icons at commit `dc7b10662a0a2cfdfc9305e2a2b06c023c30724a`. The marks are used beside readable language labels; unknown or omitted languages use a themed code icon. The same asset folder is included in the portable Admin instructions pack.

Simple Icons is published under CC0 1.0. Individual brand rights, copyrights, licenses and guidelines remain applicable. `sources.json` retains each upstream title, color, source, license and guidelines entry; `LICENSE.md` and `DISCLAIMER.md` are the unmodified upstream notices. Original artwork is not relicensed by this project. `licenses/README.md` retains attribution and the original notices for marks with supplied license data. See the linked original sources and individual license terms before reuse.

Included marks: C, C++, CSS, GNU Bash, Go, HTML5, JavaScript, JSON, Kotlin, Markdown, PHP, Python, Ruby, Rust, Swift and TypeScript. Sass is intentionally omitted because its supplied mark carries a noncommercial license. Languages without a mark at this pinned revision also use the fallback.
