# Domain Enrichment Checkpoint

This checkpoint covers read-only registrar and aftermarket enrichment. The provider relays, portfolio merge, private details, and search UI are wired locally. Use a signed-in account and real provider connections for the checks below before releasing. Start with a single connection and a small known sample of domains.

## Resume here

1. Save a private portfolio CSV export as a reference. Record the saved annual cost, registration identity, and any manually entered registrant fields for the sample. Run **Sync** from Domains and compare the same rows afterward. Confirm annual costs, notes, and provider IDs are preserved and that Afternic updates in the same operation. Exercise a failed detail read and a retry to confirm the existing snapshot stays available. Keep provider credentials and private results out of logs and issue attachments.
2. Confirm GoDaddy inventory, registrant/WHOIS settings, current renewal estimates, and pending actions on known domains. Use a PAT with domain-read access for DNS details and verify partial responses retain coverage labels. GoValue also requires an eligible subscription. Parking and live auction availability use an eligible Classic key and secret. Compare auction type, listing ID, bid data, and enrichment against the provider for an active listing. [GoDaddy Domains API](https://developer.godaddy.com/en/docs/references/rest/domains) · [Auction availability](https://developer.godaddy.com/en/docs/references/rest/auctions/check-listing-availability)
3. Compare Vercel registered inventory with the connected team's portfolio. Confirm a Vercel-managed hostname registered elsewhere shows DNS configuration on its matching private row without becoming a Vercel registration. Check Hostinger renewal dates, contact verification, nameservers, and eligible hosting metadata. With eligible keys, compare Namecheap's owned registrant and DNS details, NameSilo lifecycle flags, and Squarespace reseller details against their provider dashboards. For Porkbun, compare one recent paid invoice line to **Last Confirmed Paid Renewal** in Domain Details and verify that it leaves **Saved Annual Cost** and **Renewal Estimate** intact. [Vercel Web Analytics API](https://vercel.com/docs/analytics/web-analytics-api) · [Hostinger API](https://developers.hostinger.com/openapi/openapi.json) · [Namecheap contacts API](https://www.namecheap.com/support/api/methods/domains/get-contacts/) · [Porkbun API specification](https://porkbun.com/api/json/v3/spec)
4. Verify exact Afternic listing matches, saved Buy Now prices and estimates, last-confirmed metrics during a failed refresh, and the private account and per-domain activity reports. Check both an active listing and a domain absent from the connected portfolio. Availability and live sales depend on the actual saved credentials and provider eligibility. [Afternic Portfolio API](https://api.afternic.com/docs/portfolio-api/)
5. On `/search`, compare known taken and available synthetic names. Check signed-out versus signed-in quotes, premium and multi-year terms, and a throttled provider. Open Domain Details after a rank check and compare the latest rank and daily history with Tranco. Confirm a failed rank refresh preserves existing data and the PageSpeed result. [Tranco API](https://tranco-list.eu/api_documentation)

## Coverage gaps

- **Historical renewal charges.** Porkbun's initial sync coverage is limited to recent reconciled, undiscounted, paid invoices. Review discounted, refunded, ambiguous, and older receipts in the provider dashboard. GoDaddy's general registrar connection returns forward-looking renewal estimates. Use its receipt export or enter the verified annual cost for older charges. Hostinger's billing schema does not expose historical invoices through its registrar connection. Vercel's domain order read requires a known order ID, and domain inventory does not supply it. [GoDaddy receipts](https://www.godaddy.com/help/view-my-godaddy-receipts-4885) · [Hostinger OpenAPI](https://developers.hostinger.com/openapi/openapi.json)
- **Measured site traffic.** Tranco provides popularity rank. Afternic provides views and leads for its landers, and GoDaddy Parking provides parked-page metrics when available. Vercel's published Analytics API is project-scoped and its documented query dimensions do not include a hostname filter. A future connector needs verified per-host attribution, such as an authorized analytics property or a hostname-bearing event stream. GoDaddy and Hostinger hosting dashboards remain the source for their eligible hosted-site traffic. [Vercel Analytics API](https://vercel.com/docs/analytics/web-analytics-api#dimensions-filters-and-groups)
- **Provider access.** API access can differ from the dashboard. Keep deferred details, throttling, entitlement denial, and missing coverage visible. Full signed-in results have not been verified across all configured providers or on native.
