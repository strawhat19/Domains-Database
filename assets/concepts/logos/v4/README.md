# Domains Database logo concepts — v4: Teal records

These concepts continue the tabbed record style of [v3/02-record-stack.svg](../v3/02-record-stack.svg) with the navy and teal palette of [v1/02-domain-nodes.svg](../v1/02-domain-nodes.svg).

| Concept | Direction | Suggested use |
| --- | --- | --- |
| [01-teal-record-stack.svg](01-teal-record-stack.svg) | A direct color refinement of the three aligned records. | Header or repository identity. |
| [02-offset-records.svg](02-offset-records.svg) | Records step diagonally with bright corner tabs. | App mark or compact brand lockup. |

The SVGs use deep teal `#133B50`, aqua `#19AEAB`, muted teal `#138B8B`, and white `#FFFFFF`. Both have transparent backgrounds and editable text. Letter spacing may vary with the available sans-serif fonts.
