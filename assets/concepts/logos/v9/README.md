# Domains Database logo concepts — v9

Three new directions continue v8's paired tabbed records and the six lowercase extensions: `.com`, `.net`, `.org`, `.app`, `.dev`, and `.io`.

| Concept | Direction | Files |
| --- | --- | --- |

| Connected Index | An aqua registry spine joins three pairs of outlined and filled records. | [Logo](02-connected-index.svg) · [Icon](02-connected-index-icon.svg) |
| Folded Catalog | Six compact extension tabs sit inside a rounded catalog with one folded corner. | [Logo](03-folded-catalog.svg) · [Icon](03-folded-catalog-icon.svg) |

[Comparison sheet](04-comparison.svg) · [PNG comparison](04-comparison.png). Each logo and icon has a matching PNG export.

Palette: navy `#133B50`, aqua `#19AEAB`, muted teal `#138B8B`, and white `#FFFFFF`. Individual canvases are transparent; the comparison sheet has a presentation background. SVG geometry, extension labels, and wordmarks remain editable. Text uses Arial/Helvetica/sans-serif fallbacks; outline the selected text in a design editor when exact font rendering is needed. The detailed six-label icons suit large tiles; labels may need simplifying for a small favicon.

Prior concepts and app files are preserved. The next round belongs in `v10/`.
